# AWEN — приём предложений жанров БЕЗ GitHub для посетителей

Последнее обновление: 23 ноября 2026 года.

## Что пользователь увидит

На сайте AWEN → «Другие» → «Указать жанр» он выбирает основной жанр, поджанр и при необходимости пишет короткий комментарий.

- «Сохранить у меня» — только локальная поправка на устройстве слушателя.
- «Отправить на проверку» — анонимная отправка в общую очередь AWEN. **Кнопка активна только после подключения серверного приёмника**.
- «Скачать TXT» — резервная копия собственного предложения на устройстве; она **не отправляет** его владельцу AWEN.
- «Скопировать» — передать текст выбранным способом.

GitHub-аккаунт, регистрация и электронная почта слушателя не требуются. Успешная отправка показывается **только после ответа сервера** с номером записанного предложения. Предложения не меняют общий каталог до решения редактора.

## Как владелец получает все заявки

Открыть https://vivamusz.github.io/AWEN-/awen-genre-admin.html , ввести свой секретный ключ AWEN_ADMIN_KEY, нажать:

1. «Проверить очередь» — число всех заявок и число ожидающих.
2. «Скачать все предложения TXT» — скачивается **AWEN_Genre_Suggestions.txt**, в котором перечислены все принятые сервером предложения с названиями, авторами композиций, исходными и предложенными жанрами, датой и комментариями.

Секретный ключ НЕ хранится в браузере, GitHub или URL. Для экспорта он передаётся только в заголовке Authorization запросов к вашему приёмнику. Максимум в одном TXT — 10 000 предложений; это техническое ограничение первой версии.

## Одноразовая настройка приёмника (владелец AWEN)

**Важно:** по состоянию на 23.11.2026 код приёмника и форма на сайте подготовлены, но сервер **не развёрнут** и адрес приёмника в awen-genre-inbox-config.json пока пуст. Пока этот шаг не выполнен, автоматической доставки владельцу НЕТ.

AWEN размещён на GitHub Pages, где нет серверной базы для анонимных заявок. Для приёма используется Cloudflare Worker + приватная база Cloudflare D1. Только владелец сайта должен выполнить настройку своего аккаунта Cloudflare (можно с ПК; посетители этого не делают).

1. Создайте бесплатный аккаунт на https://dash.cloudflare.com/ .
2. На компьютере установите Node.js 20+ и скачайте репозиторий AWEN. Откройте терминал в папке проекта и перейдите в backend/awen-genre-inbox.
3. Войдите в Cloudflare и создайте D1:
   
       npx wrangler login
       npx wrangler d1 create awen-genre-inbox

4. Скопируйте выданный database_id в файл **backend/awen-genre-inbox/wrangler.toml**, заменив REPLACE_WITH_YOUR_D1_DATABASE_ID.
5. Создайте таблицу предложений в удалённой базе:

       npx wrangler d1 execute awen-genre-inbox --remote --file=schema.sql

6. Создайте уникальный длинный секретный ключ (не менее 24 символов, лучше 32+) и установите его как приватный секрет Worker:

       npx wrangler secret put AWEN_ADMIN_KEY

   Wrangler запросит значение. **Не добавляйте ключ в index.html, JSON, README, GitHub или публичную переписку**. Запомните его в менеджере паролей: он нужен для административной страницы выгрузки.

7. Опубликуйте Worker:

       npx wrangler deploy

8. Скопируйте HTTPS-адрес, например **https://awen-genre-inbox.<ваш-субдомен>.workers.dev** (это пример, не действующий адрес). В репозитории AWEN измените **awen-genre-inbox-config.json**, подставив выданный URL в api_base_url. Пример:

       {
         "schema_version": 1,
         "api_base_url": "https://awen-genre-inbox.example.workers.dev",
         "status": "ready"
       }

9. После публикации GitHub Pages протестируйте отправку одной песни в разделе «Другие». Успех должен сообщать: «Отправлено! Предложение записано в общую очередь AWEN». Затем откройте административную страницу, введите ваш секретный ключ и нажмите «Проверить очередь». Скачайте TXT и убедитесь, что тестовое предложение там есть.

**Только после шага 8** у слушателей становится доступной рабочая кнопка отправки. Пока api_base_url пуст, форма не имитирует успешную отправку и предлагает локальный TXT.

## Безопасность и модерация

- Приёмник принимает анонимные JSON-запросы только с ожидаемым Origin https://vivamusz.github.io и валидирует жанр по 20 основным категориям AWEN. Origin не защищает от спам-ботов, подделывающих HTTP-заголовки.
- Форма и сервер ограничивают размер текста, ID, комментария, используют уникальный submission_id и предотвращают повторное сохранение одного и того же номера.
- История предложений хранится в приватном D1. В опубликованном репозитории хранится **только код**, а не предложения посетителей.
- Экспорт TXT и статистика очереди доступны только по секретному ключу. Рекомендуется включить правила Cloudflare WAF / rate limiting, а при росте сайта — Turnstile против массовых автоматических заявок.
- Слушателю не нужно указывать имя, аккаунт или почту. В базу записываются ID песни, исполнитель, название, исходный жанр, предлагаемый жанр, поджанр, комментарий, дата и статус.
- Отправка не меняет автоматически awen-curation.json. Перед публикацией исправления редактор должен проверить жанр по надёжным музыкальным источникам.

## Файлы

- awen-genre-inbox-config.json — **публичный адрес** сервера приёма (не пароль).
- awen-genre-contributions.js — форма, сохранение у пользователя, отправка с проверкой серверной квитанции, локальный TXT.
- awen-genre-admin.html — закрытая ключом административная выгрузка.
- backend/awen-genre-inbox/src/worker.js — серверный приёмник, очередь, выгрузка и статистика.
- backend/awen-genre-inbox/schema.sql — таблица D1.
- backend/awen-genre-inbox/wrangler.toml — Cloudflare Worker / D1 конфигурация.
- tests/genre-inbox.test.js — тесты API, секретного ключа, CORS, повторов, TXT и состояния клиента.

**Обратите внимание:** сам факт появления файлов на GitHub не означает, что Cloudflare Worker развернут или пользовательские заявки уже собираются. Это проверяется только после настройки и реальной тестовой отправки.
