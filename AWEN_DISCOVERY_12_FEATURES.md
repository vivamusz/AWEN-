# AWEN Discover v1 — 12 инструментов музыкальных рекомендаций

**Дата:** 22 ноября 2026 года  
**Сайт:** https://vivamusz.github.io/AWEN-/  
**Открыть:** в навигации нажать **«Открытия»**.

> Все двенадцать инструментов подключены к статическому сайту. Это локальная первая версия на метаданных AWEN, а не копия закрытых алгоритмов Spotify, Apple Music и других сервисов. Функции, требующие сервера, подтверждённой истории или лицензий, имеют обозначенные ограничения.

| № | Функция | Где | Что делает | Ограничения |
|---|---|---|---|---|
| 1 | Музыка по времени (daylist) | Открытия → Главная | Утренний / дневной / вечерний / ночной микс по часам устройства | Без персональной временной модели привычек; обновление при открытии |
| 2 | Радио по треку | Открытия → Радио, в деталях песни | 25 похожих записей по жанрам, стилям, артисту, редакторским признакам | Список рекомендаций, а не лицензированная трансляция |

| 4 | Подборка по запросу | Открытия → По тексту | Запрос вида «25 спокойных песен для вечерней дороги без рэпа, 2010-х», разбор жанра, года, языка, настроения | Это парсер понятных правил без LLM; не все слова распознаются |

| 6 | 10 открытий дня | Открытия → Главная | Детерминированная новая десятка с исключением лайков, ранее открытых или прослушанных | Меньше десяти, если недостаточно подходящих треков |

| 8 | Умный порядок | Списки рекомендаций и Общие миксы | Порядок по измеренному BPM при наличии, иначе по редакторской энергии и близости жанров | Нет настоящего DJ-сведения и crossfade |
| 9 | Знакомое ↔ Новое | Открытия → Мой вкус | Регулятор персонального разнообразия относительно лайков и истории | Не глобальный рейтинг хитов |
| 10 | Общий микс по ссылке | Открытия → Общие миксы | До 50 песен; получить ссылку, импортировать, добавить и отправить новую версию | Нет аккаунтов и редактирования в реальном времени |
| 11 | Мой музыкальный год | Открытия → Статистика | Итоги с реальными прослушиваниями, поделиться текстом, скачать PNG 1080×1920 | Нет импортированной статистики Spotify/Apple; без истории честно показывает 0 |
| 12 | Фильтр подтверждённой AI-музыки | Открытия → Мой вкус | Скрывает только записи со статусом fully_ai, verified=true и достоверной ссылкой | Сейчас доказанных записей 0; неизвестное ≠ ИИ |

## Хранение и конфиденциальность

Локальные настройки хранятся в localStorage по ключу **awen-discovery-local-v1** и не синхронизируются между устройствами. Пользователь может очистить локальную историю из раздела «Мой вкус»; основное избранное AWEN хранится отдельно.

Прослушивание учитывается только при фактическом движении времени реально воспроизводимого аудиофайла приблизительно на 30 секунд. Перемотка вперёд не должна засчитываться. Короткие аудиозаписи имеют меньший порог. Простые открытия карточек учитываются как просмотры.

Ссылка на микс кодирует **только название и до 50 ID песен**; она не содержит историю, лайки и настройки пользователя. Годовая PNG-карточка рисуется локально в браузере. Приложение не загружает защищённое аудио из платных сервисов и не симулирует воспроизведение.

## Файлы и архитектура

- **awen-discovery-core.js** — ранжирование, радио, daylist, ежедневные открытия, парсер, умный порядок, статистика и share-link сериализация.
- **awen-discovery-ui.js** — интерфейс, события, история, рекомендации, экспорт PNG 9:16.
- **awen-discovery.css** — адаптивная тёмная тема.
- **awen-ai-provenance.json** — реестр доказанного происхождения треков.
- **index.html** — новая вкладка, кнопки и адаптер AWENBridge.
- **tests/discovery-core.test.js** — автоматические проверки.
- **awen-playlist-engine.js / awen-playlists.json** — пять прежних редакторских подборок работают независимо.

## Фильтр AI-музыки

Чтобы запись попала под фильтр, редактор должен сохранить в реестре действительный AWEN ID, status=fully_ai, verified=true и HTTPS evidence_url с достоверным доказательством. Не ставить статус полностью созданной ИИ-музыки на основании жанра, названия, отсутствия информации или субъективного звучания.

**На 22 ноября 2026 года в реестре 0 подтверждённых записей.** Это корректно: нет оснований объявлять реальные записи генеративными.

## Локальные проверки

Команды в клоне GitHub:

    node tests/discovery-core.test.js
    node tests/playlist-engine.test.js

Проверяются: 12 сценариев, выбор артистов и стилей, жанровые исключения, корректная обработка «2010-х», защита от неправильных ссылок, проверенный AI-статус, основы статистики, новые ссылки в HTML и неизменность пяти подборок.

## Границы первой версии

Для настоящих совместных плейлистов с одновременным редактированием, синхронизации между телефонами и полноценной музыки без выхода на официальные страницы нужен backend, авторизация и права на аудио. Для точного BPM большинства песен нужны разрешённые полные аудиозаписи. Для свободного понимания любых человеческих запросов нужна языковая модель; текущая версия использует прозрачный разбор ключевых слов. Все эти ограничения намеренно показаны посетителю сайта.
