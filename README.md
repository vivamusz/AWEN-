# AWEN Music · ӘУЕН

Музыкальный каталог сообщества [AWEN](https://vk.ru/awenqc), опубликованный через GitHub Pages.

**Сайт:** https://vivamusz.github.io/AWEN-/  
**Редактор каталога:** https://vivamusz.github.io/AWEN-/curator.html  
**GitHub Actions:** https://github.com/vivamusz/AWEN-/actions

## Что это за проект

AWEN — каталог песен, а не хостинг чужих MP3. Основные функции:

- 19 музыкальных направлений с подробными поджанрами (в том числе Phonk, House, Lo-Fi, Funk, Moombahton, Country).
- Поиск по названию, исполнителю, жанру и альбому.
- Фильтры по языку, году, настроению, поджанру и доступности.
- Пять подборок: **Спокойная дорога**, **Ночной вайб**, **Ночной вайб +**, **Танцуем**, **Чилл**.
- Избранное, карточки композиций и просмотр разрешённых источников.
- Воспроизведение через доступные официальные встраиваемые плееры и отдельно разрешённые аудиопотоки.
- Локальный редактор жанров, альбомов, годов, настроений и плейлистов.

**Не путайте:** запись в каталоге, найденная официальная страница и доступный полный аудиопоток — это три разных состояния.

## Автоматизация

GitHub Actions содержит независимые процессы:

1. **`awen-apple-backfill.yml`** — запрос метаданных по ранее найденным Apple song ID партиями; сохраняет только строго проверенные совпадения в отдельном JSON. Ключи, токены и аудиофайлы не требуются.
2. **`awen-match.yml`** — осторожное сопоставление песен с Apple Music. Ссылки публикуются только при однозначном совпадении исполнителя и названия; вместе с точными совпадениями сохраняются название релиза, год конкретного издания, длительность и жанровые метаданные. Идёт партиями и не загружает аудио.
3. **`awen-musicbrainz.yml`** — подсказки широкого жанра по жанровым тегам **исполнителя**. Это не доказательство жанра каждой песни. Существующие назначения не перезаписываются.
4. **`awen-audius-match.yml`** — независимый поиск точных совпадений, разрешённых для стриминга, через Audius.
5. **`awen-catalog-check.yml`** — проверка синтаксиса Python и JavaScript, JSON, ID, жанров и плейлистов плюс регрессионные тесты.
6. **`awen-browser-test.yml`** — открывает главную и редактор в Chromium, проверяет навигацию, фильтры, поиск, адаптивность и экспорт ручных правок.
7. **`awen-review-refresh.yml`** — пересчитывает очередь проверки и сводку при изменении музыкальных данных; список не устаревает после новых совпадений.

Данные меняются через коммиты. **Не редактируйте одновременно одну и ту же версию файла без проверки текущего SHA:** разные процессы могут добавлять ссылки и метаданные.

## Ручное редактирование без потери чужих изменений

1. Откройте [AWEN Curator](https://vivamusz.github.io/AWEN-/curator.html).
2. Найдите нужную песню, определите жанр/поджанр и при необходимости добавьте её в подборки.
3. Нажмите **«Сохранить правку»**. До экспорта она существует только в вашем браузере.
4. Нажмите **«Скачать только мои правки»**. Получится `awen-curation-patches.json`.
5. Для безопасного слияния изменений с **последней** версией общего каталога в клоне репозитория:

```bash
python3 scripts/apply_curator_patches.py awen-curation-patches.json
python3 scripts/apply_curator_patches.py awen-curation-patches.json --write
python3 scripts/test_data_pipeline.py
git add awen-curation.json
git commit -m "Apply reviewed AWEN metadata"
git push
```

Первый запуск без `--write` только проверяет содержимое. Слияние обновляет перечисленные поля изменённых треков, не затрагивает остальные записи, существующие источники аудио и новые результаты фоновых процессов.

**Не заменяйте** файл `awen-curation.json` файлом `awen-curation-patches.json`: это разные форматы. Экспорт полной резервной копии из редактора предназначен для архива, не для автоматической замены общего файла.

## Текущие ограничения автоматического заполнения

Из текущего JSON каталога можно качественно заполнить только записи, для которых
есть достаточные сведения об исполнителе и композиции. Сайт не является загрузчиком
всего архива VK: дополнительные песни нужно предоставить отдельной выгрузкой,
а прямой доступ к закрытым/лицензированным аудиопотокам не подразумевается.

- **Полный список песен:** ограничен фактически выгруженными записями `awen-catalog.json`, а не всеми возможными 5–15 тысячами публикаций сообщества.
- **Жанры:** невыясненные жанры остаются «Не определён», а не подставляются случайно.
- **Альбомы и годы:** заполнены при подтверждённых совпадениях с релизами Apple Music или ручной проверке. Год переиздания нельзя выдавать за первоначальный год песни.
- **Воспроизведение:** внешняя официальная ссылка, ограниченное предпрослушивание и полный разрешённый поток — разные возможности. AWEN не скачивает чужие MP3.
- **Проверка завершения:** `awen-audit.json` содержит автоматически вычисленные счётчики, `awen-review-queue.json` — конкретные записи с неопределённостями.

## Сверка исходного Excel (21 ноября 2026)

Повторно загружен оригинальный `AWEN_Tracks(1).xlsx`, 2 110 строк.
Номера и нормализованные названия 2 075 сохранённых записей
сверены с `awen-catalog.json`; пропавших музыкальных записей
по исходным номерам не обнаружено.

- 35 исходных строк не были загружены: это цитаты и текст публикаций,
  а не записи «исполнитель — песня» (их номера в `awen-import-reconciliation.json`).
- Ещё 16 несоответствующих музыкальной структуре строк помечены редактором,
  остаются в `awen-catalog.json` для проверки, но **не показываются посетителям**.
- Публичных музыкальных кандидатов сейчас **2 059** при 2 075 строках исходного JSON.
- Нормализации имён исполнителей в каталоге могут отличаться от оригинальных
  извлечённых строк; исходный файл Excel сохранён у владельца.
- Отчёт `awen-audit.json` показывает общее число записей и карантин отдельно.

## Качество данных

- Данные поступают из уже составленного музыкального каталога; программный доступ ко всей музыке сообщества VK пока не подтверждён.
- Некоторые строки импорта могут оказаться текстом публикации, а не названием песни. Их нельзя молча удалять или считать музыкой: для этого есть очередь проверки.
- Дубликаты помечаются, но не удаляются автоматически, потому что записи могут оказаться разными версиями или релизами.
- Жанры, определённые **по исполнителю**, — предварительные. Фактический трек может иметь другой жанр; для уточнения нужен релиз или прослушивание.
- Год Apple Music может означать выпуск альбома/переиздания, а не первое появление композиции.
- Песня без разрешённого источника сохраняется как карточка каталога, но не притворяется доступной для прослушивания.
- Автоматические проверки музыки не означают наличия прав на повторную публикацию MP3.

## Тестирование и публикация

Главный файл `index.html` лежит в корне ветки `main`. GitHub Pages использует **Deploy from a branch → main / (root)**. Установка React или Node.js для самого сайта не требуется.

Изменения интерфейса запускают браузерные проверки. При сбое смотрите вкладку [Actions](https://github.com/vivamusz/AWEN-/actions), сначала устраняйте красные тесты и лишь затем считайте публикацию проверенной.

Если после обновления сайта отображается старая версия, попробуйте обновление страницы без кэша; параметры версий у подключаемых скриптов используются для принудительной перезагрузки после изменения кода.

## Безопасность

Никогда не храните в репозитории токены VK, персональные документы, API-секреты или ключи других сервисов. GitHub Pages — публичный статический сайт. Для автоматической загрузки истории VK и защищённых административных действий потребуется отдельный серверный компонент или корректно настроенный OAuth-процесс.
