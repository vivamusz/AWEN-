# AWEN — Мои плейлисты (Personal Playlists V1)

Дата: 22 ноября 2026 года
Сайт: https://vivamusz.github.io/AWEN-/

## Три разных раздела

- Пять редакторских подборок AWEN: Спокойная дорога, Ночной вайб, Ночной вайб +, Танцуем, Чилл. Это общие списки сайта, формируемые Algotorial V2.
- Избранное (♥): единый личный список понравившихся песен.
- Мои плейлисты: неограниченные по теме личные списки пользователя с собственными именами и порядком, не меняют общие подборки. Технический лимит: 100 плейлистов по 500 записей.

## Как использовать

1. Открыть в навигации «Мои плейлисты» и нажать «＋ Новый плейлист».
2. Ввести название и сохранить новый список.
3. В каталоге AWEN нажать «＋» рядом с песней (возле ♥) либо «＋ В мой плейлист» в карточке песни.
4. Выбрать ранее созданный плейлист или прямо в диалоге создать новый и добавить композицию.
5. Открыть свой список: можно изменить порядок кнопками ↑↓, удалить песню ×, переименовать или удалить весь плейлист.
6. Из раздела «Открытия» песни также добавляются в «Мои плейлисты». Черновик «Общего микса» можно сохранить как отдельный личный плейлист.

## Хранение и резервная копия

Личные списки хранятся только в localStorage браузера под ключом awen-user-playlists-v1. В них сохраняются названия, постоянные ID композиций и порядок, дата создания и изменения. Дубликаты одной песни внутри списка не создаются.

- «Скачать резервную копию JSON» выгружает ВСЕ списки в AWEN_My_Playlists_Backup.json.
- «Восстановить из JSON» добавляет плейлисты из файла без удаления уже имеющихся. При конфликте ID плейлиста генерируется новый идентификатор.
- Песня, отсутствующая в текущем каталоге, отображается с исходным ID и может быть удалена вручную; сама запись не теряется.
- При импорте проверяются допустимые ID, формат файла, объём данных и ограничения.

Нажатие «Поделиться ссылкой» отправляет имя и не более 50 AWEN ID песен. Получатель сначала видит приглашение сохранить копию; плейлист другого пользователя автоматически не изменяется. Ссылка не включает лайки, статистику или личные настройки. Для плейлистов больше 50 песен используется резервный JSON, а не обрезанная ссылка.

Лимиты: 100 плейлистов, 500 песен в каждом, 70 символов имени, JSON до 1,25 МБ, 50 песен в одной публичной ссылке.

## Ограничения GitHub Pages

Данные личного пользователя НЕ хранятся в публичном GitHub, не синхронизируются между Android и ПК, не имеют аккаунта и могут исчезнуть при очистке данных браузера. Для синхронизации и живого совместного редактирования потребуется отдельный backend и аутентификация (например, Supabase или Firebase). Это ещё не подключено.

Списки содержат ссылки на записи каталога, а не разрешения на аудио. Воспроизведение зависит от доступного и разрешённого источника.

## Технические файлы

- awen-my-playlists.js — хранилище, создание, редактирование, порядок, резервные копии, диалог добавления и share-ссылки.
- awen-my-playlists.css — Android/desktop-стили.
- index.html — кнопки, новый раздел, модальное окно и адаптер к общему каталогу.
- awen-discovery-ui.js — сохранение рекомендаций и черновика микса.
- tests/my-playlists.test.js — проверки всех операций.
- .github/workflows/awen-discovery-ci.yml — регрессионные тесты.
