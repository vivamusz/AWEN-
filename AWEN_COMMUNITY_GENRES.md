# AWEN — категория «Другие» и предложения жанров

Дата обновления: 22 ноября 2026 года.
Сайт: https://vivamusz.github.io/AWEN-/

## Что изменилось

В каталоге AWEN есть 20 утверждённых основных музыкальных жанров. Добавлена отдельная **21-я карточка «Другие · уточнить жанр»**. Она содержит все отображаемые записи, чей основной жанр не совпадает с утверждёнными 20 названиями, в том числе «Не определён».

На момент проверки исходного awen-catalog.json и awen-curation.json: 2369 записей, из них 320 с результирующей исходной жанровой меткой «Не определён». На сайте фактическое число в «Другие» вычисляется динамически, после редакторского обогащения и исключения ошибочных импортов (поэтому число может быть меньше 320).

Категория не меняет и не удаляет старые жанры, пять редакторских подборок или исходные данные. Композиции из «Другие» теперь можно найти через карточку жанров и фильтр «Жанр» на странице «Все треки».

## Как слушателю помочь с классификацией

1. Откройте «Жанры и стили» → «Другие · уточнить жанр» или найдите любую песню в каталоге.
2. Нажмите **«Указать жанр»** (для неопределённой песни) или **«Уточнить жанр»** (если жанр уже есть). Кнопка «🏷 Предложить жанр» также находится в подробностях песни и в «Открытия» → «⋯ Ещё».
3. В форме выберите **основной жанр** из 20 направлений AWEN.
4. По желанию выберите **поджанр именно этого жанра**. Допустимо оставить поджанр пустым, если пользователь не уверен.
5. Нажмите **«Сохранить у меня»**. Композиция сразу отображается в новом жанре **только на текущем устройстве**. Исходный жанр сохраняется для отката; кнопка «Отменить мою правку» возвращает исходную классификацию.
6. Чтобы предложить исправление для **всех слушателей**, нажмите **«Отправить на проверку»**. Откроется заранее заполненная форма GitHub Issues с ID, исполнителем, названием, исходным и предлагаемым жанром. Для отправки предложения в GitHub требуется учётная запись и доступность Issues в репозитории. Действие **не отправляет его автоматически** — нужно завершить отправку в GitHub. Есть запасной вариант «Скопировать предложение» для передачи редактору иным способом.

## Почему нет кнопки «Изменить жанр сразу для всех»

AWEN размещается на GitHub Pages — статическом хостинге без пользовательской базы данных или серверного API для массового приёма правок. Нельзя разрешить любому слушателю мгновенно изменять публичную классификацию: так возможны ошибки, спам и намеренное искажение данных.

Правильная архитектура:

Пользователь выбрал жанр → локальная персональная версия → GitHub Issue (предложение) → модератор проверяет источники и контекст конкретного трека → утверждает исправление в awen-curation.json → новая версия каталога доступна всем пользователям.

Подтверждение жанра по достоверному источнику желательно; жанр исполнителя сам по себе не гарантирует жанр конкретного релиза. Для пользователя без GitHub предусмотрено копирование текста предложения, но **автоматической доставки администратору без сервера пока нет**.

## Хранение и приватность

Локальные изменения сохраняются в localStorage под ключом awen-genre-suggestions-v1, отдельно от избранного и личных плейлистов. Хранятся ID трека, название, исполнитель, исходный и выбранный жанр и поджанр, дата изменения. При очистке данных браузера локальная правка пропадёт. Исходные JSON на GitHub не меняются от пользовательского выбора.

Прямые аудиофайлы не требуются: жанр предлагается по доступным метаданным и выбору слушателя.

## Мобильная версия

Исправлены переполнение экрана карточками жанров и старые CSS-селекторы навигации по номеру кнопки. Теперь нижнее меню показывает разделы по идентификаторам, а карточки укладываются в ширину телефона. Реальную публикацию GitHub Pages и визуальную компоновку на конкретном Android следует проверить отдельно.

## Технические файлы

- index.html — категория «Другие», фильтрация, кнопка «Указать жанр», загрузка формы.
- awen-genre-contributions.js — локальные предложения, проверка жанра/поджанра, отправка на рассмотрение через GitHub.
- awen-genre-contributions.css — адаптивная форма и мобильные исправления.
- awen-services.js — применение локальных предложений после загрузки общего или личного каталога, без изменения публичной базы.
- awen-discovery-ui.js — кнопка предложения в разделе рекомендаций.
- tests/genre-suggestions.test.js — тесты соответствия поджанра, сохранения, отката, формы и пути отправки на модерацию.
- .github/workflows/awen-discovery-ci.yml — автоматические проверки при последующих изменениях.

Проверить из репозитория:
    node tests/genre-suggestions.test.js
    node tests/discovery-ui.test.js
    node tests/my-playlists.test.js
    node tests/playlist-engine.test.js

## Будущее улучшение

Если AWEN станет публичным сообществом без обязательного GitHub-аккаунта, добавить специальную форму с защищённым backend (например, Supabase) и очередью модерации: антиспам, ID песен, валидация жанров по таксономии, дедупликация предложений и редакторские статусы «Ожидает проверки / Принято / Отклонено». Сейчас это **не реализовано**.
